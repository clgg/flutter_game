## 2. 使用约束

- 本工程当前以该 Flutter / Dart 版本作为本地验证基线。
- Flame 当前使用 `^1.20.0`，在本环境解析为 `1.22.0`；不要升级到 `^1.37.0`，该版本要求更高 Dart SDK。
- Android `compileSdk`、`targetSdk` 当前由 Flutter 工具链默认值提供；Google Play 发版前仍需检查最终 AAB 的实际 `targetSdkVersion`。
- 如切换到官方 Flutter channel 或升级 SDK，必须重新跑：

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

- 发版前还需要执行 release AAB 构建和 Google Play 政策检查。
