# 割草类小游戏武器图片与打击特效素材规范

> 用途：给设计师、外包、美术或 AI 生图流程使用，明确每把武器需要什么图片、什么特效、什么尺寸、怎么命名、怎么交付。武器系统数值和购买合成规则见：`doc/ideas/割草类小游戏_武器系统购买升级合成设计.md`。

## 1. 总体美术规则

第一版统一使用：

```text
Q 版扁平 2D
+ 轻像素边缘
+ 高识别色块
+ 透明 PNG / WebP
```

武器素材不能做成写实细节堆满的小图。游戏内同屏会有大量怪物、弹体和技能，武器必须满足：

- 0.5 秒内能看懂类型：近战、投射、枪械、能量、爆破、控制。
- 图标和局内弹体同源，看起来是同一把武器打出来的。
- 高频武器不能特效过大，低频武器必须有强命中反馈。
- 所有图片必须透明背景，不能有白边、黑边、灰底、压缩脏点。
- 边缘留 4-8 px 安全透明区，避免旋转和缩放时被裁切。

## 2. 交付目录

建议后续正式武器素材放在：

```text
assets/game/grass_game/images/weapons/
  icons/
  bodies/
  projectiles/
  trails/
  hits/
  ground/
  recipes/
```

如果第一版不拆目录，也必须保留命名前缀：

```text
weapon_<id>_icon.png
weapon_<id>_body.png
weapon_<id>_projectile.png
weapon_<id>_trail_sheet.png
weapon_<id>_hit_sheet.png
weapon_<id>_ground_sheet.png
```

## 3. 通用尺寸

| 素材类型 | 推荐尺寸 | 帧数 | 用途 |
| --- | ---: | ---: | --- |
| 商店/背包图标 | 256x256 | 1 | 武器卡、购买、图鉴 |
| 小图标 | 128x128 | 1 | HUD、合成材料 |
| 武器本体 | 96x96 或 128x128 | 1-4 | 近战挥击、飞出武器 |
| 子弹/飞行物 | 64x64 | 1-4 | 弹体、飞镖、球、箭 |
| 近战刀光 | 192x192 或 256x256 | 4-6 | 扇形挥击 |
| 命中特效 | 128x128 | 4-6 | 打中敌人的爆点 |
| 爆炸特效 | 256x256 | 6-8 | 榴弹、终局武器 |
| 地面残留 | 256x256 | 4-8 | 火焰、冰霜、毒圈 |
| 电链/光束中段 | 64x256 | 2-4 | 可拉伸特效 |

尺寸规则：

- 图标用大图，局内运行时可以缩小。
- 近战和爆炸必须用大图，避免放大后糊。
- 子弹可以小，但必须留足透明边，方便旋转。
- 动画统一横向 spritesheet；复杂方向动画才需要 JSON atlas。

## 4. 图标规范

武器图标用于商店、已拥有、合成、图鉴，必须比局内弹体更完整。

图标结构：

```text
武器主体 70%-85% 画布
轻微投影或描边
透明背景
右上角可留特效能量光
```

禁止：

- 纯黑背景或纯白背景。
- 真实照片风格。
- UI 卡片背景和武器画在同一张图里。
- 复杂文字、水印、logo。
- 武器小到只占画布 40% 以下。

稀有度可由 UI 卡片控制，不建议画死在图标里。武器自身可以用少量颜色区分系别：

| 系别 | 主色 | 辅色 |
| --- | --- | --- |
| 近战 | 金黄、钢灰 | 橙色冲击光 |
| 投射 | 蓝白、青绿 | 白色速度线 |
| 枪械 | 暖黄、铜色 | 橙色火花 |
| 能量 | 紫蓝、青蓝 | 白色电光 |
| 爆破 | 赤橙、黑灰 | 黄色爆心 |
| 控制 | 冰蓝、浅紫 | 雪花或冷雾 |

## 5. 局内图片层级

每把武器建议至少有 4 层表现：

```text
武器本体 / 弹体
  -> 拖尾
    -> 命中爆点
      -> 特殊残留或二段效果
```

不是所有武器都要四张图。最低交付标准：

| 武器类型 | 必需 | 可选 |
| --- | --- | --- |
| 近战 | 图标、挥击弧线、命中冲击 | 武器本体、地面裂纹 |
| 投射 | 图标、弹体、拖尾、命中爆点 | 弹跳星星、穿透闪光 |
| 枪械 | 图标、弹体、枪口火光、命中火花 | 弹壳、暴击特效 |
| 能量 | 图标、弹体/光束、电光拖尾、命中脉冲 | 电链、屏幕小闪 |
| 爆破 | 图标、炮弹、落点提示、爆炸 | 烟尘、碎片 |
| 控制 | 图标、弹体、命中冰圈/减速圈 | 冰晶碎裂、地面霜纹 |

## 6. 打击反馈分层

### 6.1 普通命中

普通命中特效要求轻，适合高频出现：

- 4 帧以内。
- 尺寸 96x96 或 128x128。
- 持续 0.12-0.20 秒。
- 颜色跟武器系别一致。
- 不遮挡角色和敌人主体。

### 6.2 重击命中

重击用于球锤、榴弹、终局武器：

- 6-8 帧。
- 尺寸 192x192 或 256x256。
- 有明显外扩冲击环。
- 允许短暂屏幕震动和更强透明度。
- 不能每秒触发太多次。

### 6.3 状态命中

状态命中要让玩家看懂效果：

| 状态 | 视觉 |
| --- | --- |
| 减速 | 敌人脚下冰蓝圆环，边缘雪花 |
| 燃烧 | 敌人身上橙红小火苗，地面火点 |
| 电击 | 紫蓝电弧跳动，命中时短闪 |
| 击退 | 白黄色冲击波，敌人方向有速度线 |
| 吸附 | 向中心收束的紫色/蓝色线条 |
| 穿透 | 弹体穿过敌人时留下短暂裂光 |

## 7. 升级视觉层级

武器升级不能只改数字，至少做 3 档视觉变化：

| 等级 | 视觉要求 |
| ---: | --- |
| 1-3 | 基础弹体和基础命中 |
| 4-6 | 拖尾更长、命中光更亮、范围略大 |
| 7-9 | 增加副特效，如小火星、小电弧、二段冲击 |
| 10 | 武器图标加光边，局内攻击有一次明显强化帧 |

实现上可以先用运行时缩放和颜色叠加，不一定每级都画新图。但美术交付时，至少要给：

```text
普通版
强化版
满级版
```

```text

weapon_bounce_ball_icon.png

weapon_mini_grenade_icon.png

weapon_mini_grenade_warning_ring.png
weapon_mini_grenade_explosion_sheet.png
weapon_mini_grenade_smoke_sheet.png
```

规则：

- 文件名必须英文小写、下划线。
- 不要用中文文件名。
- 不要用空格、括号、版本号后缀。
- 临时素材可加 `_placeholder`，正式素材不要带 `_final`。
- spritesheet 统一 `_sheet` 后缀。

## 10. 边界与透明度要求

交付前必须检查：

- 透明背景是 alpha，不是白底或黑底。
- 图片四周没有白点、黑点、半透明脏边。
- 旋转 360 度不会裁切。
- 图标缩到 48x48 仍能识别。
- 运行时缩小到 32x32 的弹体仍能看清方向。
- 同一武器的图标、弹体、命中特效主色一致。

AI 生图常见问题：

- 边缘有白色杂点，需要抠图后清边。
- 透明 PNG 实际带灰底，需要重新导出 alpha。
- 细节过多，缩小后糊成一团。
- 光效占画面太满，局内遮挡敌人。

## 11. 第一版最小交付清单

如果要尽快进游戏，优先交付这些：

| 优先级 | 素材 |
| --- | --- |
| P0 | 每把武器 `icon` |
| P0 | 每种攻击模式 1 套通用 `projectile / hit` |
| P0 | 木棍、球锤的 `swing_sheet` |
| P0 | 榴弹和星核炮的 `explosion_sheet` |
| P1 | 火焰类 `ground_fire_sheet` |
| P1 | 冰霜类 `slow_ring_sheet` |
| P1 | 雷电类 `chain_segment / lightning_sheet` |
| P2 | 每把武器满级强化版特效 |
| P2 | 暴击、弹跳、穿透的独立小特效 |

第一版不要为每把武器都画完全独立的一整套特效。可以先按武器类型复用，再给合成和终局武器做独有表现。

## 12. 验收标准

- 商店里每把武器图标能一眼区分。
- 游戏内弹体、拖尾、命中特效不会和经验、金币、敌人混淆。
- 高频武器连续攻击时画面不脏。
- 低频武器命中有足够冲击力。
- 合成武器看起来确实像两把材料武器融合出来的。
- 终局武器必须在图标和命中特效上明显强于普通武器。
- 所有素材在浅色和深色地图上都能看清。
