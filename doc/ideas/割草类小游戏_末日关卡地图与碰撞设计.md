# 割草类小游戏：末日关卡地图与碰撞设计

## 目标

关卡主线采用“末日、变异、生存”推进：从低威胁的农场外溢开始，一路经过公路、城市、洞穴、森林、海洋、封锁区、白骨荒原、外星登陆点，最后进入宇宙裂隙。

第一版实现原则：

- 每章一张关卡选择主视觉，同时作为局内背景底图使用。
- 每章有独立主题名和小关描述，避免所有关卡都只是“清理第几波怪”。
- 局内先用代码绘制场景元素和碰撞区，后续替换正式 PNG 元素时沿用同一套 `Rect` 碰撞配置。
- 障碍物数量控制在 4 个左右，给玩家制造绕行和聚怪空间，但不阻断割草类游戏的流畅移动。

## 关卡描述节奏

每章 5 个关键体验点：

| 小关 | 体验目标 |
| --- | --- |
| 1 | 进入新区域，展示主题和基础敌人 |
| 2 | 引入快速敌人或侧翼包抄 |
| 3 | 引入任务感：样本、信标、补给、遗物、核心 |
| 4 | 加入重甲敌人和狭窄路线压力 |
| 5+ | 主题巢穴或核心战，作为进入下一章的理由 |

这样玩家每章都有“探索 -> 升压 -> 任务 -> 压迫 -> 爆点”的推进感。

## 局内背景与元素

当前局内背景由 `GrassSurvivorGame` 根据 `stageChapter` 自动切换：

- 背景底图：平铺绘制当前章节图片，避免玩家移动时离开图像范围。
- 背景压暗：叠加主题色，保证角色、怪物、掉落物和技能特效可读。
- 网格保留：弱化显示，帮助玩家感知移动速度和战场方向。
- 元素绘制：用代码绘制障碍物色块，先保证玩法，后续再替换成正式素材。

## 碰撞区域方案

当前每章 4 个矩形碰撞体，避开玩家初始点，分布在屏幕四周：

- 农场：围栏、谷仓、草垛、木栏。
- 公路：废车、油罐、巴士残骸、路障。
- 城市：楼体废墟、商铺残骸、地铁入口、坍塌墙体。
- 洞穴：岩柱、晶簇、石桥、黏液矿脉。
- 森林：树根、孢子树、倒木、灌木巢。
- 海洋：断桥、礁石、船体、潮水残骸。
- 封锁区：医疗帐篷、救护车、隔离栅栏、补给箱。
- 白骨荒原：骨堆、祭坛石、残骸墙、墓碑阵。
- 外星登陆点：坠落舱、能量塔、雷达残骸、外星结构。
- 宇宙裂隙：空间站残骸、裂隙核心、反应堆块、生物质金属墙。

碰撞规则：

- 玩家和敌人都不能穿过障碍物。
- 子弹暂时不被障碍物阻挡，避免第一版突然削弱武器手感。
- 障碍物只做绕行和聚怪，不做完全封路。
- 每章障碍物数量先控制在 4-6 个，移动手感稳定后再增加复杂地图。

apocalypse mutant survival, clear central route, readable after dark overlay,
polished game art, dramatic lighting

## 后续可玩性扩展

- 第一步：把当前代码绘制障碍物替换为透明 PNG 元素。
- 第二步：给障碍物增加类型，例如可破坏、减速区、毒雾区、补给点。
- 第三步：每章 Boss 战使用不同地形机制，例如公路油桶爆炸、森林孢子减速、宇宙裂隙重力拉扯。
- 第四步：把关卡地图配置移到远程 JSON，但只下发数值和矩形区域，不下发复杂逻辑。
