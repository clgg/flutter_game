# 割草类小游戏战斗数值平衡方案

> 目标：把当前版本从“能跑通”调到“有压力、有升级期待、能形成技能构筑”。本文记录当前默认代码参数，后续调参优先改这里对应的配置入口。

## 1. 一局体验目标

| 阶段 | 时长目标 | 局内等级目标 | 体验重点 |
| --- | ---: | ---: | --- |
| 1-1 | 145 秒 | 8-10 | 学会移动、拾取经验、第一次看到技能成型 |
| 1-2 | 170 秒 | 10-12 | 快速怪加入，开始考验走位 |
| 1-3 | 200 秒 | 12-14 | 能把一条技能树推到 5 级附近 |
| 1-4 | 230 秒 | 14-16 | 厚血怪和 Boss 压力明显增加 |
| 1-5 | 260 秒 | 16-18 | 至少形成 1 个进化技能，有机会摸到大招 |

设计原则：

- 第一关不能太难，但不能无脑站桩。
- 普通怪能被基础武器处理，厚血怪必须靠技能和武器升级加速击杀。
- 一局至少 8 次以上三选一，后续关卡目标 12-18 次。
- 通关奖励要能支撑买武器和升级武器，但不能一两局直接滚雪球。

## 2. 局内经验曲线

当前公式：

```text
requiredExp(level) = floor(7 * level^1.22)
```

| 到达等级 | 累计经验需求 |
| ---: | ---: |
| 5 | 86 |
| 8 | 272 |
| 10 | 462 |
| 12 | 708 |
| 14 | 1012 |
| 16 | 1377 |
| 18 | 1804 |
| 20 | 2295 |

解释：

- `baseExpToLevelUp = 7` 比之前稍稳，避免第一分钟升级过密。
- 怪物经验整体提高，靠掉落补足升级频率。
- 死斗模式额外使用 `1.35x` 经验需求，避免无限模式过早满构筑。

## 3. 玩家属性

| 角色 | 生命 | 速度倍率 | 攻击倍率 | 定位 |
| --- | ---: | ---: | ---: | --- |
| Male | 130 | 1.000 | 1.00 | 标准模板 |
| Female | 105 | 1.125 | 0.95 | 高机动、低容错 |
| 凹凸曼 | 220 | 1.125 | 1.05 | 均衡偏强 |
| 奥美家 | 170 | 1.250 | 0.96 | 高速风筝 |
| 金刚曼 | 320 | 1.000 | 1.18 | 近战压制 |
| 贝利牙 | 260 | 1.125 | 1.12 | 高速高攻 |
| 赛文加 | 430 | 0.750 | 1.28 | 高血高攻、走位笨重 |

局外角色等级成长：

```text
生命值 = 基础生命 + (角色等级 - 1) * 8
移速倍率 = 基础速度倍率 + min(0.18, (角色等级 - 1) * 0.006)
攻击倍率 = 基础攻击倍率 * (1 + (角色等级 - 1) * 0.015)
```

这套成长让角色等级有感觉，但不会让高等级角色直接碾压前几章。

## 4. 武器成长

当前武器继承武器库里的基础伤害和射速：

```text
武器伤害 = 基础伤害 * 角色攻击倍率 * 武器等级倍率 * 角色等级攻击倍率
武器等级倍率 = 1 + (武器等级 - 1) * 0.09
冷却倍率 = max(0.42, 1 / (1 + (武器等级 - 1) * 0.055))
升级金币 = max(70, 武器购买价 * 0.12) * 1.16^(武器等级 - 1)
```

调参意图：

- 每升 1 级武器，伤害约 +9%，攻速效率约 +5.5%。
- 冷却最低压到 42%，防止高射速武器完全失控。
- 升级成本前期可接受，中后期需要多打一两关。

## 6. 前 5 关参数

| 关卡 | 敌人数 | Boss 时间 | 强度倍率 | 通关经验 | 通关金币 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1-1 | 150 | 145 | 0.78 | 90 | 60 |
| 1-2 | 210 | 170 | 0.90 | 115 | 85 |
| 1-3 | 280 | 200 | 1.02 | 145 | 115 |
| 1-4 | 350 | 230 | 1.16 | 180 | 155 |
| 1-5 | 430 | 260 | 1.30 | 225 | 210 |

第一章主题设计：

- 主题：农场。
- 小怪：以动物小怪为主，形成“小鸡、小羊、小猪、小牛、火鸡、斗牛”等农场动物压力曲线。
- Boss：第 `1-5` 关固定为半机械鳄鱼 Boss，资源 id 为 `guaishou_cyber_crocodile_boss`。
- 后续章节也按“章节主题 + 对应小怪池 + 固定最终 Boss”的方式扩展；未完成主题设计的章节暂时使用混合 `guaishou` 小怪池和随机 Boss。

Boss 血量：

```text
Boss基础血量 = 420 + 关卡难度 * 13
实际Boss血量 = Boss基础血量 + 局内等级 * 24
```

这样 Boss 会随着玩家局内等级略微追赶，避免玩家前面刷得太顺导致 Boss 瞬间死亡。

## 7. 波次节奏

| 开始时间 | 怪物组 | 配置间隔 | 运行时实际间隔 |
| ---: | --- | ---: | ---: |
| 0 秒 | basic 组 | 0.88 | 约 0.31 秒 |
| 45 秒 | fast 组 | 0.72 | 约 0.25 秒 |
| 105 秒 | tank 组 | 1.05 | 约 0.37 秒 |

运行时会按时间把每批数量从 2 提升到 3、4。配置间隔看起来偏大，是因为运行时会乘 `0.35`，最终同屏压力仍然足够。

## 8. 掉落与结算

经验掉落：

| 概率 | 类型 | 倍率 |
| ---: | --- | ---: |
| 82% | 普通经验 | 1x |
| 14% | 高能经验 | 2x |
| 4% | 稀有经验 | 4x |

金币掉落：

| 怪物组 | 概率 | 金币 |
| --- | ---: | ---: |
| basic 组 | 18% | 1-2 |
| fast 组 | 24% | 2-4 |
| tank 组 | 40% | 5-8 |
| Boss | 100% | 40-80 |
| 死斗怪物 | 44% | 5-9 |
| 死斗稀有 | 18% | 10-17 |

通关结算：

```text
金币 = 局内拾取金币 + 关卡金币
角色经验 = 关卡经验 + floor(击杀数 * 0.35) + 局内等级 * 4
失败金币 = 局内拾取金币 + floor(关卡金币 * 生存比例 * 0.35)
失败经验 = floor((floor(击杀数 * 0.2) + 局内等级 * 2) * 生存比例)
```

技能调参原则：

- 普通技能主要提高打怪效率，不应该秒 Boss。
- 进化技能要明显改变清怪方式。
- 终极大招伤害可以夸张，但冷却必须长，并且一局最多持有 1 个。

## 10. 后续调参方向

- 如果 1-1 仍然只能升到 5 级，优先提高 `basic/lamb/piglet` 的 `expDrop`，不要先降低经验曲线。
- 如果玩家站桩能通关，优先提高 `fast/rooster` 出现比例或伤害，不要只堆 Boss 血量。
- 如果 Boss 太难，先降 `bossMaxHp` 或 `局内等级 * 24`，不要削弱小怪经验。
- 如果金币太多，优先提高武器升级成本指数 `1.16`，不要砍局内金币掉落爽感。
- 如果低攻速武器体验差，给该类武器单独做范围、穿透或爆炸补偿，不要统一加攻速。
