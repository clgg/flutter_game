# 割草类小游戏：人物武器攻击表现设计方案

## 目标

给游戏中人物增加更明确的攻击表现，同时让不同武器有明显差异。

当前项目已有 18 个武器、6 个武器家族、10 种攻击模式，并且每个武器已经配置了：

- `attackPattern`：攻击行为，例如扇形扫击、直线弹、弹跳弹、回旋、散射、链式电击、火焰喷射等。
- `effectId`：武器机制标签，例如击退、弹跳、穿透、减速、爆炸、链电。
- `muzzleFlashAssetPath`：发射或挥击瞬间的特效图。
- `projectileAssetPath`：弹体或武器飞行图。
- `fireSoundAssetPath`：开火音效。

第一版不建议为每个角色都做“攻击动作 spritesheet”。当前角色较多，武器也会继续扩展，如果做 `角色 x 武器 x 8方向` 攻击动画，资源量和维护成本会非常高。更适合现在的方案是把攻击表现拆成两层：

- 人物通用攻击反馈：所有角色共用，强调“正在攻击”的身体反馈。
- 武器专属攻击特效：按武器类型、攻击模式和 `effectId` 区分视觉效果。

## 设计原则

- 人物动作轻量化，武器差异主导表现。
- 近战、远程、能量、爆破、控制类武器必须一眼能分辨。
- 复用现有 `muzzle_*.webp`、`projectile_*.webp`，只补充缺失的命中特效和持续特效。
- 特效不改变伤害判定，避免视觉改造影响战斗数值。
- 高频攻击特效必须可复用对象或轻量绘制，避免同屏怪多时掉帧。
- 攻击表现要和当前自动攻击逻辑兼容，不要求玩家手动点攻击。

## 表现分层

### 1. 人物通用攻击反馈

人物层只表达“发力、后坐、充能”，不绑定具体武器图片。

| 武器类型 | 人物反馈 |
| --- | --- |
| 近战 | 朝攻击方向短促前冲 2-4px，身体缩放到 1.04 后回弹 |
| 投射 | 上半身朝目标方向轻微压低，发射瞬间亮一下 |
| 枪械 | 反方向后坐 2px，枪口方向闪光，低幅度震动 |
| 能量 | 身体周围出现 0.12s 充能环，颜色随武器变化 |
| 爆破 | 攻击前有 0.08s 预备压缩，发射后轻微屏幕震动 |
| 控制 | 脚下或身体周围出现冰蓝/控制光圈 |

建议新增运行时状态：

```dart
class AttackPoseCue {
  AttackPoseCue({
    required this.direction,
    required this.family,
    required this.duration,
    required this.intensity,
  });
}
```

`PlayerComponent` 根据 cue 在 `render` 或 `update` 中做偏移、缩放、闪光。第一版可以不改 spritesheet。

### 2. 武器发射特效

发射特效跟随攻击方向，出现在玩家前方。

| 攻击模式 | 发射表现 |
| --- | --- |
| `meleeSweep` | 扇形弧光、挥击残影、近身冲击线 |
| `projectile` | 单发弹体、短拖尾、枪口闪光 |
| `bouncingProjectile` | 弹球出射光点、弹跳星爆 |
| `boomerang` | 飞出轨迹和返回轨迹，两段亮度不同 |
| `coneShot` | 扇形多弹丸、枪口烟雾、散射线 |
| `beam` | 持续光束、核心亮线、外层辉光 |
| `lobbedExplosion` | 抛物线弹体、落点危险圈、爆炸云 |
| `chainLightning` | 首目标电针、跳跃闪电线 |
| `flameStream` | 连续火舌帧、火星、地面余焰 |
| `orbitSlash` | 环绕刃轨道、切割闪光、冰屑 |

### 3. 命中特效

命中特效按 `effectId` 做，让同攻击模式的武器也有差异。

| `effectId` | 命中特效 |
| --- | --- |
| `knockback` | 白黄色轻冲击环、木屑 |
| `heavy_knockback` | 地面裂纹、碎石、粗冲击环 |
| `bounce` | 小星爆、弹性拉伸残影 |
| `bounce_chain` | 弹跳点紫电星爆 |
| `pierce` | 细线切割光、穿透残影 |
| `homing` | 磁吸轨迹线、蓝色锁定点 |
| `return_damage` | 绿色回旋切割光 |
| `outer_ring_bonus` | 外圈高亮月牙刃 |
| `spark_crit` | 橙色火花、暴击小闪白 |
| `slow_25` | 冰花爆开、蓝色减速圈 |
| `spread_5` | 近距离烟雾、弹孔火星 |
| `chain_1` | 紫色链电、目标间电弧 |
| `burn_ground` | 连续火焰、地面燃烧带 |
| `burn_spread` | 扇形火星雨、命中爆燃 |
| `explosion` | 爆炸火球、烟尘、冲击波 |
| `ice_orbit_slow` | 冰刃切割、冰屑、减速环 |
| `heavy_thunder` | 重击冲击环、落雷、电流扩散 |
| `gravity_explosion` | 星核爆心、吸附涡旋、二段闪爆 |

## 素材规划

### 现有素材继续使用

当前已有：

- `assets/game/grass_game/images/weapons/weapon_*_icon.webp`
- `assets/game/grass_game/images/weapons/muzzle_*.webp`
- `assets/game/grass_game/images/weapons/projectile_*.webp`

这些素材可以继续用于：

- 武器选择页图标。
- 发射瞬间的 `muzzle`。
- 弹体或飞行武器的 `projectile`。

### 建议新增素材目录

```text
assets/game/grass_game/images/weapons/hit/
assets/game/grass_game/images/weapons/trails/
assets/game/grass_game/images/weapons/cues/
```

命名规则：

```text
hit_<effect_id>_sheet.webp
trail_<weapon_id>_sheet.webp
cue_<family>_<style>_sheet.webp
```

示例：

- `hit_heavy_knockback_sheet.webp`
- `hit_slow_25_sheet.webp`
- `hit_gravity_explosion_sheet.webp`
- `trail_return_sickle_sheet.webp`
- `trail_flame_sprayer_sheet.webp`
- `cue_melee_swing_sheet.webp`
- `cue_firearm_recoil_flash_sheet.webp`

### 规格

| 类型 | 建议尺寸 | 帧数 | 用途 |
| --- | --- | --- | --- |
| 人物 cue | 128x128 spritesheet | 4-6 帧 | 充能环、后坐闪光、挥击提示 |
| 近战弧光 | 192x192 spritesheet | 6-8 帧 | 木棍、球锤、链锤 |
| 命中特效 | 128x128 spritesheet | 4-6 帧 | 普通命中、冰、雷、爆炸 |
| 火焰喷射 | 256x128 spritesheet | 6-8 帧 | 连续火舌 |
| 爆炸 | 192x192 spritesheet | 8 帧 | 榴弹、星核炮 |
| 电弧 | 192x96 spritesheet | 4-6 帧 | 链电、雷暴 |

素材要求：

- 透明背景。
- 不带文字、水印、UI。
- 画面中心留锚点，避免播放时抖动。
- 火焰、电、冰、爆炸都要有亮暗变化，不能只是单帧闪烁。
- 同类素材颜色和形状统一，方便玩家形成识别。

## 代码实现建议

### 1. 新增攻击表现事件

新增轻量运行时模型：

```dart
class WeaponAttackVisualCue {
  WeaponAttackVisualCue({
    required this.weaponId,
    required this.family,
    required this.attackPattern,
    required this.effectId,
    required this.origin,
    required this.direction,
    required this.intensity,
  });
}
```

触发位置：`GrassSurvivorGame._fireWeaponPattern`。

每次自动攻击开始时创建 cue：

- 推送给 `PlayerComponent` 做人物攻击反馈。
- 推送给 `WeaponVisualEffectSystem` 或当前 game 内列表做武器特效。

### 2. 玩家组件增加攻击反馈

`PlayerComponent` 增加：

- `triggerAttackCue(...)`
- `_attackCueTimer`
- `_attackDirection`
- `_attackFamily`

渲染时根据 cue 做：

- 位置微偏移。
- 缩放。
- 充能环或闪光。

注意：不要直接改变真实碰撞半径，只改变视觉绘制。

### 3. 武器特效映射

建议新增配置：

```dart
class WeaponVisualProfile {
  const WeaponVisualProfile({
    required this.pose,
    required this.muzzleStyle,
    required this.projectileStyle,
    required this.hitStyle,
    required this.trailStyle,
    required this.screenShake,
  });
}
```

映射优先级：

1. `weaponId` 精确匹配，用于终局武器和特色武器。
2. `effectId` 匹配，用于命中特效。
3. `attackPattern` 匹配，用于基础发射方式。
4. `family` 兜底，用于人物反馈。

### 4. 命中特效触发点

当前命中判定集中在 projectile 和范围伤害逻辑中，建议在以下位置触发：

- 子弹命中敌人：生成 `HitEffect`。
- 近战扫击命中：生成近战冲击。
- 爆炸范围伤害：生成爆炸中心特效。
- 链电伤害：生成电弧线。
- 火焰持续伤害：只在首次命中或周期性低频触发，避免过多特效。

## 分阶段落地

### 第一阶段：不新增大量素材，先强化代码表现

目标：1-2 天内让攻击明显变好。

- 人物攻击 cue：前冲、后坐、缩放、充能环。
- 近战弧光：用 Canvas 画扇形，不依赖新图。
- 枪口闪光：继续使用现有 `muzzle_*.webp`。
- 弹体：继续使用现有 `projectile_*.webp`。
- 爆炸和雷电：先用代码绘制环、线、粒子。

优点：最快可玩，风险低。

### 第二阶段：补充 GPT 特效 spritesheet

目标：让效果更真实、更炫。

- 生成火焰喷射 spritesheet。
- 生成雷电链 spritesheet。
- 生成爆炸 spritesheet。
- 生成冰霜命中 spritesheet。
- 生成近战挥击弧光 spritesheet。
- 替换代码绘制的临时效果。

### 第三阶段：终局武器专属表现

目标：让合成武器有期待感。

- 天雷链锤：重击后落雷。
- 星核榴光炮：爆心吸附和二段爆炸。
- 冰月轮：持续环绕冰刃。
- 焚风散射器：扇形燃烧弹。
- 雷暴弹球：弹跳电弧。

### 第四阶段：攻击表现和手感联动

目标：让反馈更像完整动作游戏。

- 重武器加入轻微屏幕震动。
- 爆炸命中加入短暂停顿感。
- 暴击或进化技能触发更强命中特效。
- 低血 Boss 命中特效增强。

## 验收标准

- 玩家静止时也能明确看出角色正在攻击。
- 不同武器仅看特效就能分辨大类。
- 火焰喷射必须是连续燃烧，不是单帧闪烁。
- 雷电必须有目标间连接线，不只是命中点闪光。
- 爆炸必须有落点、爆心、冲击波三层。
- 近战武器必须有方向性弧光，不只是敌人掉血。
- 同屏 100+ 敌人时，攻击特效不能明显卡顿。
- 特效关闭或缺图时，游戏仍可正常运行。

## 推荐优先级

优先做 6 个基础表现族，覆盖当前全部武器：

1. 近战扫击：训练木棍、球锤、天雷链锤。
2. 普通投射：飞星镖、磁能短弓、火花手枪、冰霜法杖。
3. 弹跳投射：弹力球、雷暴弹球。
4. 回旋武器：回旋镰、月牙回旋镰。
5. 范围爆破：小型榴弹炮、星核榴光炮。
6. 元素持续：火焰喷壶、雷针发射器、冰月轮、焚风散射器。

这 6 类完成后，当前武器系统的攻击辨识度会有明显提升，而且不会引入难以维护的人物攻击素材组合。
