Generated with GPT image generation for the current survival arena game style.

- `option_02_dragon_boss`: boss pressure + hero scale, strongest game fantasy signal.
- `option_03_coin_gem_weapons`: reward + weapon system signal, lower character identity.

## Files

Each option contains:

- `source_1024.png`: master square source.
- `preview_256.png`: quick preview.
- `android/res/mipmap-*/ic_launcher.png`: Android legacy launcher sizes.
- `android/res/mipmap-*/ic_launcher_foreground.png`: Android foreground files matching the current project density sizes.
- `android/res/mipmap-anydpi-v26/ic_launcher.xml`: adaptive icon XML.
- `ios/AppIcon.appiconset/`: iOS AppIcon files and `Contents.json`.

The candidates are not wired into the app yet. To apply one, copy that option's Android `res` files into `android/app/src/main/res/`, and copy the iOS `AppIcon.appiconset` contents into `ios/Runner/Assets.xcassets/AppIcon.appiconset/`.
