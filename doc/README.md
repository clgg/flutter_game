## 6. 文档放置规则

- 新增玩法、数值、素材和体验方案放到 `doc/ideas/`。
- 新增架构、模块边界和通用技术方案放到 `doc/architecture/`。
- 新增发布、商店、隐私和合规检查放到 `doc/release/`。
- 新增本机环境、构建环境和排障记录放到 `doc/environment/`。
- 新增平台专项说明放到 `doc/platform/`。
- 根目录不要新增普通 Markdown 文档；只有 `AGENTS.md` 作为代理规则入口保留在根目录。
