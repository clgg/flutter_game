# iOS 启动图资源说明

原说明来自 `ios/Runner/Assets.xcassets/LaunchImage.imageset/README.md`。为避免 Markdown 文档散落在工程目录中，统一迁移到 `doc/platform/`。

可以通过替换 `ios/Runner/Assets.xcassets/LaunchImage.imageset/` 下的图片来自定义启动图。

也可以打开 Flutter 项目的 Xcode 工程：

```bash
open ios/Runner.xcworkspace
```

然后在 Xcode Project Navigator 中选择 `Runner/Assets.xcassets`，把需要的启动图资源拖入对应位置。
